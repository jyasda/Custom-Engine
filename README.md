# Custom-Engine
A fully custom build mechanical engine build in On Shape. Includes 2 working pistons controlled by gears connected by a motor, and has accounted space to put the battery's and motors. Pitsons are connected to a 50 teeth gears which are connected to smaller gears directly connected to the motor shaft. Ultimately took around 25 hours to complete.

The engine consists of 2 pistons, each individually moving, 2 motors connected to the pistons using gears, and a main chamber in which every thing would fit in and the pistons would slide at the top, similar to a regular car engine.
